# Meloday Music landing page

A buildless, responsive one-page site. Serve `dist/` with any static HTTP server.

The public download is marked coming soon. When releases are available, replace that label with the confirmed installer URL. The planned project home is https://github.com/melodaymusic.

Artwork and the walkthrough come from the existing app promo. Nunito is bundled with its font licence. The day selector is a cover-colour preview, not a playable music demo.

The Windows desktop app source and installation are independent of this site.
